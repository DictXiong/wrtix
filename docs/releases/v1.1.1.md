## wrtix 1.1.1

### Changes

- Structured, bounded diagnostics for MAC-related failures in the complete official
  OpenWrt VM acceptance suite. Original exceptions and rollback deadlines remain
  authoritative; private console, credentials and transaction files stay private.
- Synthetic regressions for observation scope, boot identity, stale witnesses,
  failure handling and the normal release workflow.
- Controller/agent implementation and capability contract are unchanged from
  1.1.0. This version retains its configuration import, secret providers,
  prerequisite preparation and optional `--diff` workflows.

### Usage

Pin the Nix input to `github:DictXiong/wrtix/v1.1.1` and install the signed agent
APK using the [installation instructions](https://github.com/DictXiong/wrtix/blob/v1.1.1/feed/README.md).
Complete pending transactions before upgrading. Existing network settings and
login credentials remain preserved.

### Validation and limits

Affected synthetic checks passed. One focused official OpenWrt 25.12 MAC sequence
completed both guarded reboots; earlier intermittent VM reboot failures remain
unexplained. This update does not claim a GRUB, QEMU or product runtime fix.
Publication requires the normal Nix checks, a fresh signed SDK package and the
complete official VM acceptance suite. Physical wireless and hardware offload
remain downstream acceptance responsibilities.

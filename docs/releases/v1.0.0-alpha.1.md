## wrtix 1.0.0 alpha 1

Declarative OpenWrt configuration with Nix and confirmed SSH transactions.
This is an experimental pre-release; configuration rollback is not firmware rollback.

### Features

- NixOS and standalone Nix interfaces for UCI, files, services and package requirements.
- Runtime SOPS secrets, SSH host-key verification and first-device enrollment.
- Independent rollback, receipt recovery and management-address handoff.
- User-defined profiles and checks through the generic resource interface.
- AP and minimal quick-start templates without a mandatory topology or hardware model.

### Installation

The attached `wrtix-agent` APK is built by the pinned official OpenWrt 25.12.0
SDK. It contains architecture-independent scripts. OpenWrt 25.12 with APK 3 is
the initial supported package environment; other releases and opkg/IPK are not yet accepted.

Download the APK, `wrtix-v1.0.0-alpha.1.pem`, `SHA256SUMS` and `release.json`.
Follow the [installation and provenance verification instructions](https://github.com/DictXiong/wrtix/blob/v1.0.0-alpha.1/feed/README.md).
Install Nix on the controller, not on OpenWrt. Installing the agent preserves
existing networking and login credentials; configuration changes require explicit deployment.

### Validation

Publication requires `nix flake check`, a real SDK build and the signed APK's
installation, replacement and removal in the official OpenWrt x86_64 VM.
VM acceptance covers initialization, idempotency, address handoff, receipt recovery,
required-check failures, guarded reboot and timeout rollback. Pending transactions
must reject package removal and replacement before runtime files change.

The VM does not establish physical Wi-Fi performance, VLAN/PPE behavior,
non-x86 runtime compatibility or firmware sysupgrade compatibility.

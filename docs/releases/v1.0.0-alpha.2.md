## wrtix 1.0.0 alpha 2

This pre-release aligns the standalone agent package, Nix controller and firmware
integration on one pinned source revision. The resource protocol and existing
configuration remain unchanged from alpha 1.

### Installation

Use the attached architecture-independent `wrtix-agent` APK on OpenWrt 25.12
with APK 3. Verify the checksums, provenance and signing key before installation;
follow the [installation instructions](https://github.com/DictXiong/wrtix/blob/v1.0.0-alpha.2/feed/README.md).
The Nix controller runs on the deployment host. Installing the agent alone does
not change networking or login credentials.

### Validation

Release checks cover Nix evaluation, controller and agent regression tests, a
pinned official SDK build, and signed package lifecycle tests in the official
OpenWrt VM. Physical firmware integration is additionally checked on a supported
ARM router before publication; this does not replace longer stability testing
or establish compatibility with every OpenWrt target.

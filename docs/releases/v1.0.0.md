## wrtix 1.0.0

Declarative OpenWrt configuration with a Nix module and standalone controller,
runtime SOPS secret resolution, and an architecture-independent router agent.
Deployments use authenticated device identities, bounded transactions, independent
rollback protection, and receipts for recovery after a controller disconnect.
Profiles and extensions use the same resource validation and ownership rules.

### Installation

Use the attached signed `wrtix-agent` APK on OpenWrt 25.12 with APK 3. Follow the
[installation and provenance verification instructions](https://github.com/DictXiong/wrtix/blob/v1.0.0/feed/README.md),
then pin the deployment host's Nix input to `github:DictXiong/wrtix/v1.0.0`.
Installing the agent does not change network settings or login credentials.
Router firmware may also include the matching agent.

### Validation and boundaries

Release CI checks Nix evaluation, controller and target regressions, the pinned
official SDK build, and signed package lifecycle acceptance in the official
OpenWrt VM. ARM router integration additionally covered deployment and repeated
dual-stack AP/VLAN checks during an approximately seven-hour observation window.
The planned eight-hour run was interrupted by a controller restart; it is not
claimed as a completed eight-hour test.

The resource protocol and runtime behavior are unchanged from alpha 2.
Package requirements validate installed packages; deployment does not install
arbitrary packages or roll back firmware. Other OpenWrt releases and package
managers require separate compatibility validation.
